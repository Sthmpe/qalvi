# Geist fonts

These are the Geist and Geist Mono variable Latin WOFF2 files previously served
by Google Fonts through `next/font/google`. They preserve the existing English
UI typography while allowing development and builds without font downloads.
Both support weights 100–900 and are loaded through `next/font/local`.

Upstream: https://github.com/vercel/geist-font

The shared SIL Open Font License is included in `OFL.txt`.
