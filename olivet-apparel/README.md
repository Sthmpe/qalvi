# Olivet Apparel

The portfolio and booking website for **Olivet Apparel**, a fashion design house.

This is not a magazine template or an online shop. It's a **digital atelier**: visitors walk through the designer's studio, see how each piece goes from sketch to finished garment, find the style they want, try it on with AI, and book it, all without being distracted or confused.

> Status: **Planning.** No code yet. This folder holds the agreed vision, architecture and roadmap so the build can start cleanly.
